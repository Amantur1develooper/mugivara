# Импорт цветов в магазин (филиал id=45)

Скрипт: `shops/management/commands/add_flowers.py` (уже в проекте).
Фото: 15 файлов в этой папке — бесплатные (CC0 / CC BY) стоковые фото похожих
цветов, подобраны вручную. **Это не ваши реальные фото** — как появятся свои,
перезалейте через личный кабинет (Товары филиала → фото товара), это проще,
чем через скрипт.

## Как запустить на сервере

1. Задеплойте проект как обычно (эта папка `flower_photos_import/` и файл
   команды уже лежат в репозитории — просто попадут на сервер вместе со всем
   остальным).
2. Зайдите на сервер и выполните из корня проекта (там, где `manage.py`):

   ```bash
   # сначала репетиция — ничего не пишет в БД, просто показывает что будет
   python manage.py add_flowers --branch-id 45 --photos-dir flower_photos_import --dry-run

   # если всё ок — реальный запуск
   python manage.py add_flowers --branch-id 45 --photos-dir flower_photos_import
   ```

   Скрипт создаст категорию «Цветы» (если её ещё нет), 15 товаров с фото,
   ценой-заглушкой и описанием, и остаток **25 шт** на филиале 45.

3. Скрипт безопасно перезапускать повторно — не создаёт дублей (ищет товар по
   названию), только обновит остаток на 25 и подставит фото/описание, если их
   ещё не было.

4. **Обязательно проверьте и поправьте цены** в личном кабинете (Товары
   филиала → филиал 45) — в скрипте они проставлены ориентировочно, реальных
   цен указано не было.

5. После первого успешного запуска эту папку `flower_photos_import/` можно
   удалить из проекта — она нужна только один раз, для самого импорта.
